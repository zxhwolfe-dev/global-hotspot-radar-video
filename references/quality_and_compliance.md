# 发布前质量与合规门槛

## 内容

- [ ] 比较实时 Radar、站外热榜和官方/权威网站，并执行原文核查；记录实际扫描量、快照状态和失败/不可用情况。最终候选区分 radar/web/mixed，站外题不伪造 Radar ID 或分数，覆盖不全不宣称全网扫描。
- [ ] 与既往节目查重；相同事件若再做，已说明今天新增事实。
- [ ] 每个关键结论可追溯到 `source_manifest.json` 的具体来源。
- [ ] `final/content_audit.json` 已完整记录事实与来源、安全/版权/隐私、目标平台规则和编辑风险，且为 PASS；中文或投放中国平台的版本另含中国政策，英文海外版另含目标市场规则。
- [ ] 按 `editorial_platforms.md` 区分作者输入、助手执行、第三方资料、编辑推断、模拟示例与未知项；没有把助手操作写成作者亲历，也没有把“报道未提供”写成“事实不存在”。
- [ ] 动态数字记录时间或使用保守表述。
- [ ] 中英文按 `editorial_platforms.md / 双轨受众的共享与隔离` 分别核对观众问题、入口、背景和叙事；不把当前视频号50+基线外推为所有中文受众，也不把英文默认当作美国市场。
- [ ] 英文候选在选题确认时附中文译题，但除非明确要求双语成片，英文封面、生成卡、字幕、编辑标签和公开文案均无新增中文内容。
- [ ] `selection_report.json` 说明每个最终题材的今日新增事实、观众收益、一手证据、可视证据、未知项和编辑切入点。
- [ ] 新项目已按 `selection_and_research.md` 运行 `check_selection_research.py --require` 并处理错误，结果保存在 `preview/selection_research_check.json`；`STRUCTURE_OK` 只代表结构检查，`NOT_CONFIGURED` 不是完成检查。旧项目不因本规则回写升级。
- [ ] 按 `editorial_platforms.md / 在现有编辑轮次中检查结构性模板` 检查承诺兑现、真实转折与段落功能；关键删改有记录，未取得近期稿件时注明未比对。
- [ ] 每条新闻有清楚的主线与本题的信息价值，不只翻译公告或添加泛用建议；结尾没有另起话题、泛泛升华或为互动改写方向。必要评论有依据，没有为了具体、生动而加入不能支持主问题的故事。
- [ ] 按事实 → 结构 → 文字完成编辑，再拆视觉节拍；标题、旁白和画面结论已回核主体、时间角色、范围、数字/单位、因果、确定性、材料归属及相邻句的额外暗示。理解必需的条件在对应主张附近，不只核数字。
- [ ] “看这里”“随后”等指示与实际素材对应；官方实拍、预测/模拟帧、生成示意、作者实拍及助手截图已按身份区分，没有用来源权威性代替画面的证明能力。
- [ ] 互动可缺省。保留的问题与本题直接有关，观众已有回答依据；首评有增量，不靠捆绑无关新闻或隐藏关键事实。
- [ ] `editorial_quality` 指向当期完整定稿、首读实际复述、带来新理解或让人想跳过的具体句段、关键删改和保留判断的依据；独立审稿与分步自查如实区分，正式去标签口播与定稿一致。事实通过、技术通过、文本可理解性与编辑吸引力评估不相互代替；只填 PASS 或描述“短句口语化”不算编辑证据，也不以编辑自评承诺真实留存。

存在同题公众号成稿时，按 `editorial_platforms.md` 比对标题入口、中心问题、事实顺序、结尾和主素材；无配对作品时记为未比对，不算失败或已通过。教学题才检查公平的直接 AI 基线，不把新闻一律改成教程。

## 平台与市场合规

- [ ] 所有语言版本都不以未核实信息制造恐慌或群体对立，并检查事实安全、版权、肖像、商标和隐私风险。
- [ ] 无投资收益承诺、医疗治愈承诺或替代专业意见。
- [ ] 医学内容明确试验阶段、适用人群、获批状态和数据缺口。
- [ ] 中文或投放中国平台的版本已检查中国现行政策与对应平台规则；政治、法律、灾难、未成年人等高风险题材已查询最新规则并做人工复核。
- [ ] 英文 TikTok、Reels 或 YouTube Shorts 版本已按目标平台和目标市场规则复核，没有仅因系列含中文版本就机械套用“中国政策”结论。
- [ ] 评论引导围绕事实、产品和证据判断，不诱导攻击。
- [ ] 内容质量、素材权利、原创声明资格、生成内容声明、推荐与付费加热分别判断；涉及发布或加热时查询对应平台当前官方要求，不把公众号结论移用视频。没有实际平台反馈就不编造结果，不以文案改善承诺推荐、加热或审核通过。

## 画面与素材

- [ ] 封面对应当期题材，显示时间不拖沓。
- [ ] 每条新闻的结构、色彩和视觉隐喻不同，但系列整体风格一致。
- [ ] 遮住字幕抽查事实、证据、机制、边界和判断卡：每张至少有一个可独立读取的信息锚点，连续画面没有“只有漂亮主体、全靠字幕讲内容”的空转。
- [ ] 关键数字、短结论、对比、时间线、因果路径、证据原话等采用与题材匹配的不同形式；画面不是统一信息框，也没有为追求丰富堆成小字墙。
- [ ] 画面主信息、辅助信息和主体层级清楚；关键文字优先位于上部或中部，下部正常参与构图，代表帧中字幕与内容没有明显打架，也没有大块无意义死区。
- [ ] 一行和两行字幕均已抽帧复核；底板透明度均匀，行间、转角和宽窄行交界处没有半透明背景重复叠加形成的黑块、接缝或重影。
- [ ] 相邻字幕 cue 没有时间重叠，淡入淡出期间不会同时显示两块字幕背景；正式1080p至少抽查一张两行字幕帧和一个 cue 切换边界。
- [ ] 关键事实截图保留原始像素；模型生成的网页、数字或标志未被当作证据。
- [ ] 纯文字新闻页未被当作小字正文截图塞进成片；没有手机端可读证据区时，已改用数据图、事实可视化、相关实景或题材化画面。
- [ ] 纸张、相框、文件夹和证据窗在稳定态没有无意义空白；原始截图保留像素并通过底托、裁边、阴影或色温与生成背景自然衔接。
- [ ] 所有外部视频有来源、时间码和使用依据，引用短且必要；来源与权利先于水印外观，无水印不等于可用，驳回或裁切不替代授权/使用依据核查。
- [ ] 每段外部视频已比较动作前奏、高潮和结果；最终入选片段既有信息增量，也在正常速度下包含最有辨识度的动作、结果或现场反应，而不是随手截取的普通过程。
- [ ] 中文发布版已人工检查其他平台标志、账号信息、关注/榜单界面、二维码和水印；发现时已区分“自动审核风险”与“确认侵权”，并把替换或申诉选择交给用户。
- [ ] `final/visual_risk_report.json` 已生成并逐项人工复核；自动扫描只写 warning，不改变发布状态、不删除素材、不自动重做。
- [ ] 原声与画面来自同一时间点，口播和字幕在原声窗口让位。
- [ ] 原声窗口、预填首帧、生成纸框与标签使用同一实测矩形；540p和1080p的静态前、淡入中、稳定播放、淡出末及结束后画面均无位置跳变，也未遮挡标题、标签或关键数字。
- [ ] 原片与设计窗口比例不同时，播放器内的 letterbox 留边在视觉上均衡；除非构图有明确理由，不能只在一侧出现明显黑条。
- [ ] 静态图无无意义平移、推拉、晃动或循环缩放。
- [ ] 透明图层有真实 alpha；每个动作与题材语义对应，动作结束后画面稳定，代码没有渲染新闻文字。
- [ ] 透明图层动作在正常速度下能看清起势、动作和结果；多动作未挤在同一瞬间，且动作后留有足够稳定阅读时间。
- [ ] 同题和跨题转场不同，所有边界前/中/后采样无黑白帧。
- [ ] 新复杂卡使用 `scene_v2` 时，`final/motion_quality_report.json` 无 blocking error；正常速度、慢放和手机尺寸检查均能看清预备、行动、收势与稳定结果。
- [ ] 主动作与口播重音、证据或原声事件直接对应；去掉动效会损失理解或注意力引导，而不只是少了装饰。
- [ ] 需要建立题目身份的镜头已判断是否适合标题入场；含关键数字的镜头已判断是否适合数字锁定、刻度推进、分组揭示或对比翻面。所有文字和最终数值均来自已生成且逐字复核的图像层，没有由代码临时重绘新闻事实。
- [ ] 标题、关键数字、证据和结果动效已错峰分布；没有全部在开头两秒完成，也没有同时争抢注意力。数字动画若缺少可靠中间值，只揭示准确终值，不制作虚假递增过程。
- [ ] 已查看运动覆盖图：长卡的视觉事件没有全部集中在开头，旁白进入新事实、机制、证据或结论时，画面有相应状态变化或切换；不存在十几秒“字幕在变、画面论点不变”的空转。
- [ ] 点击、扫描、连线、盖章、划改等功能型动作均展示了目标响应和结果态，不是只有光标、箭头或贴纸自身移动。
- [ ] 复杂卡已抽查动作前、峰值、结果态和口播中后段；主动作、辅助响应和音效错峰且有层级，没有同时抢注意力，也没有动作结束过早导致后半段再次僵住。
- [ ] 丰富度来自题材化状态变化、空间遮挡、证据揭示和原声，而不是增加无意义漂移、循环缩放、通用粒子或同质音效。
- [ ] 同一动画预设没有跨多卡机械复用；无法对齐、没有信息增量或不产生目标响应的透明动效已删除，而不是为了“有动效”勉强保留。

- [ ] 每张卡实测≤12秒，相邻同静态图不通过换ID延长；图片中信息、比例、主张与口播一致。素材入库前的水印复核记录与实际文件一致。

## 语音与同步

- [ ] 开场招呼实际时长合格；英文默认不超过2.5秒。
- [ ] 文本复核与音频听检分开记录；未实际听到标为未听检，不以 ASR 或文本复述代替。实际有条件时已在正常倍速下不看稿试听一整条新闻；voice.instruction 已写“中速偏快、利落流畅”，实际听感同样达到快而清楚，句尾没有拖腔，连续句式没有统一慢拍。若反馈偏慢，已先删冗余并调整表演指令，而不是压缩波形或牺牲呼吸缝。
- [ ] 情绪和拟声标签被执行但未被读出；严肃题材的情绪克制。
- [ ] 字幕等于去标签后的口播，时间只覆盖实际旁白。
- [ ] 已听检每个相邻口播边界：上一段完整结束、下一段未抢入，两段之间有与语气相符的自然呼吸缝。
- [ ] 已逐句核对无截音、丢音节或尾辅音；末句已单独完整听完，没有被画面或封装时长提前截断。
- [ ] 视频时长不短于音轨；最终卡可见到音轨结束。
- [ ] 从末句最后一个可听音素结束起计，实际静音约0.8秒，推荐编码后0.75–0.90秒。

## 已验证的经验

- 真实视频和原声比对静态图做无意义运动更能提升现场感，但只在有一手素材时使用。
- 把官网截图作为 Imagen 参考图会提升视觉融合，却可能改写日期和数字；最终证据层必须保留源像素。
- 其他平台页面或账号界面可能触发微信视频号的自动版权/引流限制，但平台提示可能在申诉后撤销。以后先做风险提示和来源核对，不把机器提示直接当成侵权结论，也不未经用户确认自动重做。
- 仅把 `tail_hold_sec` 写成0.8不足以保证听感，TTS 段可能自带尾静音；必须检测最终音轨。
- TTS 提供者的段落时长和波形阈值可能使后一段抢入，也可能切掉末句尾音；逐边界实听和末句单独完整性检查不可省略。
- 联系表如果只按固定前段采样，可能漏掉后半集。最终联系表应覆盖完整时长。
